# Sample campaign

Approved kit from a live budget-profile run for Tamsin Hollow Roasters, a fictional brand. Real publishers appear only as cited research sources. Raw web research is left out of the repository.

| File | Contents |
| --- | --- |
| `kit.html` | The kit as a standalone page |
| `kit.md` | The kit in Markdown |
| `kit.json` | The full kit: strategy, assets, claims appendix, issue ledger, and cost |
| `run_log.jsonl` | The run's timeline, including failed tool calls |

Seven assets shipped and every claim is supported. One image prompt was rejected because it called the farm "small", which no approved fact states, so the kit records that decision and its reason.
